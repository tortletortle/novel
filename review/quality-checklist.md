# 单章质量检查清单

## 连续性

- [ ] 时间、天气、距离和移动耗时没有冲突。
- [ ] 人物位置、伤势、衣着、物品和能力保持一致。
- [ ] 人物只知道其有渠道获知的信息。
- [ ] 称谓、专名和规则符合设定表。
- [ ] 本章没有意外提前回收或遗忘活跃伏笔。

## 场景与情节

- [ ] 视角人物在每个场景中都有具体目标。
- [ ] 阻力真实影响选择，而非装饰性冲突。
- [ ] 场景结束时局势、关系或认知发生变化。
- [ ] 巧合只制造麻烦，不直接解决核心问题。
- [ ] 结尾钩子来自人物选择或因果链。

## 人物

- [ ] 主要人物说话方式可以区分。
- [ ] 行动符合人物欲望、恐惧、能力和认知。
- [ ] 情绪变化有触发过程。
- [ ] 配角不是单纯的信息投放工具。

## 语言

- [ ] 删除重复解释和读者已经理解的信息。
- [ ] 抽象情绪尽可能落实为可观察细节。
- [ ] 没有连续使用模板化比喻、排比或机械转折。
- [ ] 没有无意义的“微微、缓缓、不由得、似乎、仿佛”堆积。
- [ ] 正文里没有大纲术语、写作分析或 Agent 说明。

## 提交前

- [ ] 章节标题和元数据正确。
- [ ] 章纲标记的关键任务已经完成。
- [ ] 需要作者决定的问题已单独列出。
- [ ] 作者确认后才更新 `state/`。
