# 文风指南

> 将本文件里的示例和规则替换成你真正想要的文风。具体规则优先于“写得优美”之类的抽象要求。

## 叙事气质

- 基调：【冷峻 / 明快 / 克制 / 荒诞 / 其他】
- 节奏：【偏快 / 中等 / 偏慢】
- 描写密度：【低 / 中 / 高】
- 幽默程度：【无 / 少量 / 明显】

## 句法与用词

- 平均句长：【待定】
- 是否允许网络用语：【待定】
- 是否允许生僻词：【待定】
- 专有名词规则：以 `bible/terminology.md` 为准。

## 视角规则

- 默认采用第三人称限知。
- 只描写当前视角人物能够感知、回忆或合理推断的内容。
- 切换视角必须换场，并在章纲中明确标记。

## 对话规则

- 对话必须服务于人物目的、关系变化或信息冲突。
- 避免角色互相讲述双方都知道的背景资料。
- 重要人物应在人物卡中记录口头习惯和绝不使用的表达。
